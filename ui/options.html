四库存目源流

分类体系映射与自定义方案

可装一套预置方案（杜威十进、中图法等），也可新建或导入自定义分类体系。数字编码始终识别，字母编码在对应方案启用后生效。

每行一条类目，格式：编码 名称 | 给模型看的说明（编码支持 1–3 位数字或字母）。
行首缩进 = 二级类目，挂在上一条一级类目下；二级编码用「父首位 + 10n」，例如 110、120，每个父类最多 9 个。

因书立目

从收藏里归纳分类法

按域名分层抽 200 条交给模型归纳两级骨架，再用规则铺到全部收藏，装不下的类目自动剪掉。产出只是草稿：改名、勾掉不要的类目之后，点「落成目录」才会真的建文件夹。

只处理还没归入任何类目的条目，不建目录、不改结构。
个人习惯沉淀

改判记忆规则

当你在 AI 归类或整理计划中手动「改判」特定域名时，归藏会自动记住你的偏好，后续本地规则优先命中，并作为示例提示给大模型（公共平台如 GitHub / 知乎不会绑定整站）。

数据与隐私安全

本地存储管控与备份恢复

所有检测记录、标签批注、改判记忆与 API Key 均严格保存在本地 chrome.storage.local，绝不上传至任何第三方云端。

书签树快照备份与安全恢复 整树结构快照，环形保留最近 3 份。恢复时会自动先备份当前树，并将快照重建到带时间戳的新文件夹，绝不覆盖现有书签。
