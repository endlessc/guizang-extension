模型配置

任何兼容 OpenAI 规范的 /chat/completions 均可使用：DeepSeek、通义千问、Kimi 或本地 Ollama（http://localhost:11434/v1）。不配置 Key 亦可离线使用，系统将自动退回本地关键词分卷规则。

检测参数

检测在扩展后台发出真实轻量请求，获取实际状态码与网络连通耗时。一次探测过多容易触发源站防护，建议保持默认并发与超时。

文人色彩系统

典籍配色方案

以宣纸、徽墨、汝窑、蜜蜡与漆器等传统器物文脉为灵感，精心调校 6 套古典雅致色系，兼顾高对比度易读性与沉浸审美，即刻全景同步至管理台、侧边栏与弹窗。

四库存目源流

分类体系映射

归藏遵循「因书立目」的典藏传统。可装一套预置方案（杜威十进、中图法等），装好后按方案归位；也可以只读取书签栏里已有的编码目录。数字编码（如「000 综合与工具」）始终识别，字母编码（如「T 工业技术」）只在对应方案启用后生效。

数据与隐私安全

本地存储管控

所有检测记录、归类建议与 API Key 均严格保存在本地 chrome.storage.local，绝不上传至任何第三方云端。

书签树备份 整树结构快照（不复制书签），环形保留最近 3 份；整理功能必须先备份才允许动手。
